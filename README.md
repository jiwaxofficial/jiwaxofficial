## 📌 Overview

**jiwax** is an all-in-one web utility box designed with a sleek retro terminal simulator interface. It delivers zero-latency micro-tools, converters, and arcade mini-games directly in your browser.

---

## ✨ Key Features

### 🛠️ Everyday Micro-Tools
- **QR Code Generator:** Instant QR code creation for links, text, and credentials.
- **Random ID Generator:** Quick generation of UUIDs, secure tokens, and random strings.
- **Text-to-Speech (TTS):** Convert written text into audio using modern speech APIs.
- **Text Utilities:** Fast case converters, line formatting, and encoding/decoding.

### 🔄 Local File & Text Converters
- **Browser-Based Processing:** Convert files and text safely inside your web browser.
- **Zero Server Uploads:** Data never leaves your machine, ensuring full privacy and peace of mind.

### 🎮 Terminal Arcade Games
Take a quick productive break with lightweight retro games right inside the prompt:
- 🧩 **2048**
- 👾 **Space Invaders**

### 🔌 SDK & Embed Support
Easily integrate jiwax terminal features into your own applications with the lightweight SDK embed module available at `/embed.jiwax`.

---

## 🔒 Privacy & Security

jiwax operates on a strictly **stateless architecture**:
* 🛡️ **100% Local Execution:** All utilities and conversions run directly within the client browser.
* 🚫 **No Tracking or Logs:** No tracking cookies, no server logs, and no external storage of user input.
* ⚡ **Ultra Fast & Lightweight:** Minimal footprint designed for high performance on modern web platforms.

## ⚡ Quick Start

### Live Web Access
Visit the live terminal interface directly at: **[https://www.jiwax.icu/](https://www.jiwax.icu/)**

### Interacting with the Terminal
1. Open [jiwax.icu](https://www.jiwax.icu/) in any web browser.
2. Type `help` to list all available tools and commands.
3. Type any utility command (e.g., `qr`, `tts`, `2048`) and press `Enter` to get started.
